Private lifecycle tax

tool_open · 0.71 MiB

Serialized ToolInteraction at open. Always action: {type: unknown}, status: pending, timing/failure null. Used to replay a row when a sibling generation is subtracted. Not queried by the protocol. ~291 B × 2,566.

tool_merge_state · 1.05 MiB

{fields: [{field, stamp: {rank, order}}]}. Occupied fields: lifecycle_status and completed_at on all 2,566; plus failure_kind and failure_diagnostic on 87. Stamps carry source identity + generation + offset. This is the largest remaining on-row JSON.

tool_update_fact · 0.86 MiB logical

5,132 patches, 2.04 MiB pages, 2.11 MiB indexes. Observed occupancy: status 5,132, timing 2,566, failure 87. request and outcome are always null here because unknown actions never carry a typed body to patch.

file_edit · 0.50 MiB pages

Still filled from native Edit/Write names at normalize time, not from ToolAction::FileChange. 666 edit + 202 write, 216 distinct paths, no snapshot_ref. Cheap, and the only remaining file-shaped fact in SQLite.

What this round did not do

No image sidecar on C

Campaign B wrote 54 files / 14.77 MiB under <db>.images/ from Read toolUseResult.file.base64. Unknown tools do not walk that native payload, so C has neither .images/ nor .assets/. The pixels still live only in the ledger.

No text members

CanonicalText::externalize spills inline text above 32 KiB to /api/assets/<blake3>.txt. Chat max is 23 KiB. Unknown actions have no command/diff/file fields to spill. Zero members.

Full-home ingest is a different story

run-ingest-2026-08-30_16-35-02-904-766d35 failed after metadata with duplicate cold tool openers on a repeated native tool id (branch replay). It left 318 named files under rosetta.sqlite.assets (178 txt, 85 jpg, 47 png, 8 pdf, 31.3 MiB) and no published SQLite. Not mixed into C’s totals. Uncommitted opener last-writer-wins is the fix for that failure; it is not in campaign C.

An earlier typed run was slower

09-28-21 / 09-29-16 already had 3,934 rows and 14.19 MiB SQLite, but stage-7 apply was 4,258 ms (cold wall 5.2 s) before the in-memory private-cold fold. C is the same schema with that fold: 270 ms apply, 1.17 s wall.

The remaining apply cost is no longer fat TEXT. Stage 7 on C is 270 ms for 12,557 ops; FTS sync is 242 ms for 1.25 MiB of prose. Framing is 62 ms of a 755 ms stream phase (the rest is ledger append). If the pin is widened to 2.1.197–2.1.200, SQLite will grow by whatever the typed actions keep (paths, commands, diffs as CanonicalText, outcomes) and .assets/ will start to appear for oversized members and authored images — still without putting native toolUseResult back into the row.
